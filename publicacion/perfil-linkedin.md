## Proyecto

### SoporteLab — Laboratorio personal de mesa de ayuda IT

Aplicación web educativa desarrollada para practicar el ciclo completo de gestión de incidencias: registro y priorización de tickets, seguimiento de activos, documentación del diagnóstico, control de vencimientos y creación de una base de conocimientos. Incluye datos ficticios reproducibles y un script PowerShell de diagnóstico Windows de solo lectura.

**Tecnologías:** Python, Django, SQLite, HTML, CSS, JavaScript y PowerShell.

**Aclaración:** proyecto personal educativo; no representa una implementación productiva ni experiencia laboral para una empresa o cliente.
