# Video demostrativo

El video se genera a partir de siete escenas 16:9 con capturas reales de SoporteLab y textos en pantalla. No utiliza voz ni música para que pueda reproducirse silenciado en LinkedIn sin perder el mensaje.

Ejecutar desde la raíz del proyecto:

```powershell
.\scripts\export-video.ps1
```

Resultado: `dist/Benjamin_Luduena_Demo_SoporteLab.mp4`.

Todos los usuarios, activos, incidentes y métricas visibles pertenecen al escenario ficticio de demostración.
